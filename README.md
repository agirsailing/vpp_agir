# Velocity Prediction Program (VPP)
A velocity prediction program (VPP) for the moth to analyse its performance.

## Contributing
For members of the Ägir sailing team to contribute to the VPP development. This will create a local working 'copy' of the project on your computer.

`
git clone https://github.com/agirsailing/vpp_agir.git
cd vpp_agir
`
